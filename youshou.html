有兽小厨房

致敬《有兽焉》· Q版休闲经营手游UI概念设计
游戏UI Q版卡通 休闲经营 治愈系
项目概述
一套可爱到想马上玩的甜品店经营界面

🎮项目定位

致敬《有兽焉》治愈系风格的同人向概念设计练习。用马卡龙色系统一登录、主界面、玩法三个核心场景，把"接单-配餐-上菜"的经营玩法闭环用可视化组件完整表达。

🎯设计目标

  • 借鉴治愈系 IP 氛围，探索 Q 版休闲游戏 UI 的视觉表达
  • 用一套可复用的组件规范支撑全部界面
  • 让玩法规则一眼看懂，降低上手门槛
  • 与《众生之门》形成风格对比，展示设计跨度

📄交付内容

  • 登录页（加载动线 + 治愈系氛围定调）
  • 主界面（信息架构 + 场景叙事）
  • 玩法界面（经营玩法闭环）
  • 配色 / 字体 / 组件规范

📅项目周期

个人独立项目，设计周期约1周。

注：角色形象为 AI 辅助生成的原创近似形象，非官方素材，仅作风格参考；本作品为同人向概念设计练习，非商业授权项目。

🛠️设计工具

即时设计（界面排版与组件库）、豆包AI / 即梦AI（图标与素材生成）、Photoshop（精修与切图）

设计思路
从风格定调到玩法可视化的完整思考过程

1为什么做这个项目

《众生之门》是暗色森林 + 手绘风，偏重氛围还原。但游戏 UI 实习岗会考察风格多样性，所以我刻意选了完全相反的调性——粉嫩 Q 版、治愈系、休闲经营，证明自己能驾驭不同风格的界面设计。

2风格定调

  • 马卡龙粉 / 奶黄 / 浅蓝三色系，营造温馨治愈的甜品店氛围
  • 全圆角 + 软萌造型，符合 Q 版休闲游戏的目标用户画像
  • 爪印 / 甜点 / 爱心贯穿全局，强化治愈系风格认知

3视觉层级与触控

  • 三张图围绕"登录→主界面→玩法"完整流程，学会串联场景
  • 每张图的主操作（开始 / 上菜）都放在底部拇指热区
  • 资源栏独立置顶，功能按钮分区排布，信息一目了然

4组件化思维

  • 资源栏、状态栏、按钮、订单气泡均为可复用组件，而非一次性画死
  • 统一圆角、描边、投影参数，保证多界面一致性
  • 预留按压态 / 选中态 / 禁用态，为开发交接做准备

5玩法可视化

把"顾客订单→食材选择→上菜"的游戏规则用 UI 表达清楚，让玩家不读教程也能上手。这是游戏 UI 区别于普通 APP UI 的核心——做"玩法翻译"，而不只是画好看的皮。

6与《众生之门》的关系

两个作品为一对组合：《众生之门》展示还原 IP 氛围、做沉浸式界面的能力；《有兽小厨房》展示把握休闲品类、表达玩法逻辑的能力。一个偏氛围，一个偏交互，覆盖游戏 UI 的两大核心能力。

文字按钮 · 清除
主按钮（开始 / 上菜）采用高对比粉色渐变 + 大圆角，用于每屏唯一核心操作；清除为低权重操作的图标按钮。所有按钮统一大圆角胶囊造型，符合 Q 版休闲调性。
资源栏 · Resource Bar
资源栏固定在主界面顶部，采用粉色半透明胶囊样式，图标 + 文字组合。爱心（红）、金币（黄）、钻石（蓝）用三种明确不同的主色区分，保证语义可读。
状态栏 · Status Bar
玩法界面的核心状态栏：倒计时、得分、满意度三项并行置顶。倒计时在最后一分钟进入危险态（描边变色），给玩家紧迫感；满意度实时反馈表现。

界面展示
三张核心界面的设计要点说明

登录页 · 有兽焉

粉黄马卡龙配色 + 满屏甜点图案，第一眼传递治愈甜品游戏调性；爪印融入标题强化治愈系风格认知。

💡 设计亮点：加载进度条上的奔跑小动物让"等待"变成有期待感的过渡，是登录页的动线巧思。

主界面 · 有兽小厨房

粉色厨房场景 + 四只小动物围桌做甜点，界面不只是功能堆叠，而是有生活感的叙事画面。

💡 设计亮点：左侧玩法/任务、右侧系统功能分区明确；资源栏独立置顶；"开始"作为唯一主按钮放底部拇指热区。

玩法界面 · 甜品经营

顾客订单气泡 → 食材托盘 → 上菜/清除，三步完成一单的经营玩法闭环，规则一眼看懂。

💡 设计亮点：倒计时 + 得分 + 满意度三项状态栏让玩家实时感知表现；订单需求可视化，不读教程也能上手。
